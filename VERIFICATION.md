# Проверка NetPulse 1.0.6

31 октября 2026 года. [Исправление REALITY](docs/REALITY-FIX-1.0.6.ru.md) · [JSON](VERIFICATION.json).

| Проверка | Результат |
|---|---|
| Компоненты Rust | 142 теста библиотеки, 5 контроллера, 10 службы и 2 интеграционных теста TLS/gRPC пройдены |
| Реальные REALITY-профили | 2 профиля, 4/4 HTTPS-запроса через «Авто» и проверка готовности NetworkCore пройдены в локальных прокси |
| Миграция ядра | Прежний встроенный файл заменён официальным 1.14.4; параметры профилей не изменены |
| Запуск и настройки | 9 проверок запуска, 15 групп IPC, перенос данных и сохранение настроек пройдены |
| Интерфейс | RU/EN × светлая/тёмная темы: по 8 страниц и 22 кадра без ошибок QML |
| Установщик | Установка, обновление, удаление и сохранение данных проверены в отдельном контуре с заглушками системных операций |

Контрольные суммы оригинального sing-box сверены с официальным выпуском.
Архив исходников содержит оригинальные корни sing-box/Xray и 168 проверенных
модулей Go. [Результат проверки официального ядра](docs/OFFICIAL-SING-BOX-AUDIT-1.0.6.json)
сохраняет замечания сканера; бинарный анализ не доказывает доступность каждого
пути из NetPulse и не даёт основания объявлять программу свободной от уязвимостей.

Рабочий TUN, системный прокси и исходная база пользователя не менялись.
Проверка состояния «Подключено» выполнена через сетевую библиотеку с локальными
слушателями, без включения режимов Windows. Живое обновление службы/UAC и
переключение TUN не выполнялись. Два IPv6-теста исключены по ограничению Windows
10013. Новый вердикт антивируса не получен.
