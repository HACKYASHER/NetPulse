# Проверка NetPulse 1.0.7

29 октября 2026 года. Обычный стабильный выпуск с исправлением первого запуска.
[Причина ошибки](docs/FIXES-1.0.7.ru.md) · [Результаты JSON](VERIFICATION.json).

| Проверка | Результат |
|---|---|
| Компоненты Rust | 139 тестов основной библиотеки, 5 контроллера, 8 службы и 2 интеграционных теста TLS/gRPC пройдены |
| Запуск готового клиента | 9 проверок пройдены, включая существующий профиль по умолчанию, разные рабочие папки, старый файл блокировки, второй процесс и восстановление после аварийного закрытия |
| Ошибки папки/блокировки | Отображаются отдельно от сообщения о работающем клиенте |
| Команды клиента | 15 групп пройдены, включая сохранение настроек, профилей и пинга |
| Перенос профиля | Зашифрованные данные и настройки сохраняются; посторонние файлы не удаляются |
| Интерфейс Windows Qt | RU/EN, светлая/тёмная темы: 8 страниц и 22 кадра на вариант, без ошибок QML |

Проверка запуска использует настоящую сборку Qt, обычный Windows-плагин и
профиль в папке отдельной тестовой копии приложения. Она проходит ту же
подготовку профиля, что и обычный запуск, без подстановки `--data-dir`.
Работающий процесс проверяется в изолированном режиме без VPN. Именно этот
путь раньше не покрывался тестами интерфейса с отдельной папкой данных.

Изначальная настройка теста с отсутствующим плагином offscreen была исправлена;
итоговый прогон с Windows-плагином прошёл. Это не изменение плагинов выпуска.

## Ограничения и унаследованные проверки

Два IPv6-теста по-прежнему ограничены средой Windows 10013; независимая
проверка этого ограничения выполнена в 1.0.6. Реальная установка с UAC,
TUN/системный прокси и поведение Касперского в этом прогоне не проверялись.
Сценарий установщика меняется только номером выпуска; его полный тест
установки/обновления/удаления в отдельном контуре проводился для 1.0.6.
Исправленная обработка истории путей проверена отдельно и через запуск GUI.

Версии зависимостей и байты обоих встроенных ядер сохранены от 1.0.6:
Xray 26.10.21 и sing-box 1.14.4-netpulse.1. Результаты их аудита и оставшиеся
замечания Qt/Go приведены в [предыдущем аудите](docs/SECURITY-AUDIT-1.0.6.ru.md).
Новый вердикт антивируса не получен. Личные подписки, рабочая служба,
системный прокси и маршруты не менялись при проверках.
