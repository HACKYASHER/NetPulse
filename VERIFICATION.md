# Проверка NetPulse 1.0.5 — восстановление службы

29 октября 2026 года. [Исправление](docs/SERVICE-REPAIR-1.0.5.ru.md) · [JSON](VERIFICATION.json).

| Проверка | Результат |
|---|---|
| Компоненты Rust | 140 тестов библиотеки, 5 контроллера, 10 службы и 2 интеграционных теста TLS/gRPC пройдены |
| Восстановление | Проверены владелец, текущий путь, остановленное состояние, заполнение отсутствующего комплекта, сохранение посторонних файлов и прекращение операции при внешнем удалении |
| Готовый клиент | 9 проверок запуска, 15 групп IPC, перенос профиля и сохранение настроек пройдены |
| Интерфейс | RU/EN × светлая/тёмная темы: по 8 страниц и 22 кадра, без ошибок QML |
| Установщик | Установка, повторная установка, удаление и сохранение данных проверены в отдельном контуре с заглушками системных операций |

Поведенческие тесты выполнены до переименования номера 1.0.8 в выбранный
пользователем 1.0.5. Готовые исполняемые файлы 1.0.5 затем проверены отдельно.
Два IPv6-сценария исключены по ранее подтверждённому ограничению Windows 10013.
Живая регистрация службы, UAC и соединение TUN в этом прогоне не менялись.
Новый вердикт антивируса не получен. Замечания для неизменённых зависимостей
из [аудита компонентов](docs/SECURITY-AUDIT-1.0.6.ru.md) остаются применимы.

Версии ядер: Xray 26.10.21 и sing-box 1.14.4-netpulse.1. Их байты и исходники
сохранены. Для уже установленной 1.0.7 нужен ручной запуск установщика 1.0.5.
