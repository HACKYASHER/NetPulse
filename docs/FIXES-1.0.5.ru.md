# NetPulse 1.0.5

Установщик собирает компоненты и личные данные в одной папке. Профиль переносится
при первом запуске обычным пользователем, с проверкой базы и хешей до удаления
совпавших исходных файлов. Неизвестные и заблокированные файлы не удаляются.

Исправлена установка выбранного ядра при отсутствующем втором ядре. Дополнение
недостающих компонентов выполняется только в явно запрошенной установке; фоновый
запуск не пытается бесконечно восстанавливать удалённые защитой файлы.

Подробности структуры: [INSTALLATION.md](INSTALLATION.md).
Результаты проверок и ограничения: [VERIFICATION.md](../VERIFICATION.md).
