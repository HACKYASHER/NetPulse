# Восстановление службы в NetPulse 1.0.5

Windows могла сохранять регистрацию `NetPulseCoreQt`, указывающую на
`<папка NetPulse>\service\NetPulseService.exe`, после исчезновения папки службы.
Соединение завершалось ошибкой Windows 3, а кнопка «Установить / восстановить»
запускала обычное обновление, которому требовался полный старый комплект.

Теперь кнопка запускает отдельное явное восстановление. Доверенный установленный
помощник проверяет путь службы и владельца, подтверждает остановку через SCM,
проверяет исходные ядра и собирает комплект через транзакцию замены файлов.
Операция требует обычного подтверждения Windows. Повторный запуск полного
установщика также выбирает восстановление, если регистрация осталась, а файлы
отсутствуют. Удаление остановленной регистрации допускается и при отсутствии
папки службы.

Обычные подключения и обновления ядер не восстанавливают отсутствующие файлы.
Если компонент исчезает во время восстановления, операция прекращается без
повторного копирования. Ошибка содержит полный путь. При обнаружении антивирусом
сначала следует изучить его отчёт; исключения и настройки защиты не меняются.

Проверки владельца, пути и состояния службы, заполнения пустого комплекта,
сохранения посторонних файлов и удаления компонента во время транзакции
покрыты тестами. Живая установка с UAC и соединение TUN в этом прогоне не выполнялись.
