# Ревью NetPulse 1.0.7

Применён code-review-skill, зафиксированный в VERIFICATION.json. Проверялись
поведение и границы доверия, а не массовое изменение стиля. Полный перечень
проверок и ограничений — в [VERIFICATION.md](../VERIFICATION.md).

| Найденная причина | Исправление и подтверждение |
|---|---|
| Уровень в журнале менял настройки ядра и прерывал VPN | Отдельный фильтр с «Все записи» по умолчанию; QML-тест подтверждает отсутствие сохранения настроек |
| Ротация и чтение только хвоста скрывали старые записи | Дневные файлы, пять дней хранения, страницы по 500 строк с ограничением чтения 1 МиБ; тесты переходов, старых ротаций и изменённых файлов |
| Выбор файлов удерживал блокировку контроллера и не имел родителя окна | Асинхронный диалог Qt с transient parent, типизированный абсолютный путь и ограниченный фоновый I/O; нативные, IPC и lifecycle-тесты |
| Запоздалые команды, диагностики и STOP службы могли пересечься | Флаг закрытия, поколения заданий, повторные проверки под блокировкой, отказ до запуска после SCM STOP; результаты отменённых работ не возвращаются после очистки |
| Автовыбор мог продолжить работу после отключения настройки | Повторная проверка auto_failover перед активацией и между кандидатами; ручная смена сервера во время VPN требует подтверждения |
| Недоступный первый адрес скрывал рабочий адрес другой семьи | Ограниченные параллельные TCP-попытки с чередованием семей; тест резервного адреса, обновление частичных результатов |
| Обновление подписки каскадно удаляло сохранённый пинг | UPSERT сохранённых идентификаторов, удаление только исчезнувших профилей; тест обновления и кэша после перезапуска |
| Резервная копия теряла пинг, вытесненный из истории | Совместимое сохранение независимого кэша, атомарное восстановление и проверка внешних настроек |
| Сравнение MTU перезапускало ядро на каждом кандидате | Узкий SetMtu с PID/session, LUID/GUID и пределом исходного буфера; проверка обеих семей, readback и возврат при частичной ошибке |
| Speed Test иногда сообщал о пустом ответе на границе времени | Естественное завершение сохраняет уже принятые данные; реальный пустой первый ответ остаётся ошибкой |
| Служба могла использовать другой комплект ядер | Сравнение трёх SHA-256 перед TUN; явная синхронизация после обновления, понятный отказ при незавершённом обслуживании |
| В установочный каталог попадали docs и прежние сведения о сборке ядра | Минимальный runtime, сохранённые лицензии, удаление только устаревших путей из прежнего манифеста; тест сохранения личных и посторонних файлов |
| Метаданные/журналы могли читаться до проверки размера или через ссылку | Ограничение до выделения полного буфера, проверка обычных каталогов/файлов; недопустимые пути и ссылки отклоняются |

Чужие маршруты, адаптеры, прокси/PAC и изменённые внешними программами записи
не удаляются массово. Нет команд оболочки или путей к конфигам в IPC службы.
Проверка TLS, SNI, ключей и сертификатов сохранена; не добавлялось обходов
проверки сертификатов или антивируса. Новые настройки не переписывают ключи
и параметры REALITY в исходных профилях.

Проверки конкретных сценариев не доказывают отсутствие всех конфликтов
с будущими версиями Windows, драйверов, антивирусов и серверов. Замечания
сканера к неизменённым официальным ядрам перечислены отдельно и не скрыты.
