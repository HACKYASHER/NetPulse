# NetPulse 1.0.0 beta

[<kbd>English</kbd>](https://github.com/HACKYASHER/NetPulse/releases/tag/v1.0.0-beta)

Нативный VPN-клиент для Windows с Qt Quick, контроллером на Rust, sing-box и Xray. Для подключения используется собственный сервер или подписка.

- Общий список серверов и подписок, закрепление профилей, контекстные действия и обновление подписок при запуске и по интервалу.
- Флаги стран, выбор режима и ядра, копирование прямого и VPN-адреса, автоматический пинг активного подключения.
- Маршрутизация по имени EXE, значки приложений, отдельный JSON с правилами, импорт и экспорт, исключения доменов.
- Вкладки DNS, MTU, SNI/TLS, фрагментации, multiplex, службы TUN и проверяемого обновления и отката ядер.
- Анализ пути для MTU и сравнение кандидатов по скорости и задержке с повторными замерами и сверкой исходного значения.
- История измерений, адреса Speed Test, сетевые группы процессов и события подключений приложений.
- Цветные журналы с копированием, переведённые категории и слежение за журналом. Исправлены светлая и тёмная темы и меню трея.
- Проверка обновлений при запуске и каждые шесть часов. Временные загрузки очищаются, предыдущие ядра сохраняются для отката.
- Установщик поддерживает обновление, восстановление и удаление с сохранением настроек и подписок. Служба TUN устанавливается через стандартное окно UAC.

Доступны **NetPulse-Setup.exe** и **NetPulse-Portable.zip** для Windows x64, исходники, лицензии и контрольные суммы SHA-256.

Это бета-версия с неподписанными исполняемыми файлами. Проверка TUN с повышением прав и сравнение MTU на удалённом VPN отдельно не выполнялись. Сравнение MTU в этой версии переподключает VPN несколько раз и может использовать до 36 МиБ полезного трафика плюс расходы протокола. Результат зависит от сети и отражает условия замера.

NetPulse 3.0.4 доступен как архивная предварительная версия.
