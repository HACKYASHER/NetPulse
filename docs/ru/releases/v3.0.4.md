# NetPulse 3.0.4, архивная версия

[<kbd>English</kbd>](https://github.com/HACKYASHER/NetPulse/releases/tag/v3.0.4)

Версия 3.0.4 сохранена как резервный вариант. В выпуске доступны исходные
исполняемые файлы и исходники. Тег указывает на самостоятельный архивный снимок.

Текущий клиент использует нативный интерфейс Qt. [Последний выпуск](https://github.com/HACKYASHER/NetPulse/releases/latest)

Архивная версия использует прежнюю архитектуру Rust, Tauri и React. Перед
подключением в другом клиенте отключите текущий. Чтобы перенести данные,
создайте резервную копию в старом клиенте и восстановите её в новом под той же
учётной записью Windows.
