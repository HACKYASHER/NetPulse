# NetPulse 1.0.10

[<kbd>English</kbd>](https://github.com/HACKYASHER/NetPulse/releases/tag/v1.0.10)

В обновлённый установщик 1.0.10 входит официальный [Xray 26.11.9](https://github.com/XTLS/Xray-core/releases/tag/v26.11.9). Названия тем переведены, а «Анимации интерфейса» оформлены таким же переключателем, как соседние настройки. Если 1.0.10 уже установлена, запустите новый установщик и выберите «Обновить». Клиент предлагает автообновление только при повышении номера версии.

- Диагностика проверяет Windows после ошибки подключения и при сбое периодической HTTPS-проверки активного VPN. В отчёте видны системный прокси, маршруты, TUN, MTU адаптера, состояние службы времени, оценка отклонения часов и сравнение настроек с активным сеансом.
- Проверка файлов называет недоступные компоненты клиента, службы TUN и ядер. Рабочие ядра восстанавливаются из встроенного комплекта. Для службы доступно штатное восстановление, а при повреждении встроенных файлов можно скачать официальный установщик.
- Анимация NetPulse показывает загрузку, диагностику и изменение состояния подключения. Вкладки, кнопки, переключатели, меню и диалоги получили плавные переходы. Отключить эффекты можно переключателем «Анимации интерфейса» в общих настройках.
- При завершении работы контроллер перестаёт обновлять меню трея после его закрытия.
- Журнал выравнивает начало строк по левому краю. Переход к последним записям возвращает горизонтальную прокрутку к началу строки. Если файл сменился при подгрузке истории, клиент заново читает последние записи. Чтение дат можно повторить после ошибки, а запоздалые ответы игнорируются после закрытия вкладки.
