# NetPulse 1.0.3 beta

[<kbd>English</kbd>](https://github.com/HACKYASHER/NetPulse/releases/tag/v1.0.3-beta)

Восстановлена запись соединений ядер и исправлена автоматическая настройка IPv6 для раздельной маршрутизации.

- sing-box и Xray получают выбранный уровень журналирования. INFO включает обычные соединения. При смене уровня для активного подключения используется проверенный перезапуск с откатом.
- При смене категории журнал сбрасывает горизонтальную прокрутку и выделение. Записи загружаются после обновления модели и даты. Ошибки загрузки и чтения видны в интерфейсе.
- Журнал читает последние 500 строк из текущего и архивных файлов в пределах 256 КиБ. Пустой текущий файл больше не скрывает архивные записи ядра.
- Для TUN доступны «Авто», «Только IPv4» и «IPv4/IPv6». В «Авто» раздельная маршрутизация с белым списком или прямым режимом без физического маршрута IPv6 использует IPv4. Глобальный VPN сохраняет IPv6 через сервер.
- Клиент проверяет совместимость службы TUN до остановки рабочего подключения.

В предоставленном журнале было 91 сообщение об ошибках. Из них 66 относились к тайм-аутам прямых подключений, 23 — к недоступным адресам IPv6, 2 — к прерванным DNS-запросам по HTTP/2. Тайм-ауты остаются видны, проверка TLS и правила приложений сохраняются.

Автоматические проверки использовали локальные серверы и тестовые данные. Настройки TUN, DNS, MTU и прокси рабочего подключения не менялись. При обновлении установите текущую службу TUN через стандартное окно UAC. Старые службы не принимают новые настройки.
