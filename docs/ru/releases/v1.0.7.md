# NetPulse 1.0.7

[<kbd>English</kbd>](https://github.com/HACKYASHER/NetPulse/releases/tag/v1.0.7)

- Уровни в «Активности» стали фильтром просмотра. По умолчанию показаны все записи; VPN при смене фильтра не перезапускается. Добавлены старые страницы и хранение файлов журналов за пять дней.
- Сравнение MTU меняет только MTU принадлежащего сессии адаптера, без перезапуска ядра. Проверяются исходное значение, кандидат и восстановление. Верхняя граница ограничена исходным буфером ядра; малые HTTPS-пробы не измеряют скорость скачивания.
- Исправлены тайм-ауты TCP при недоступном адресе одной семьи, показ частичных результатов пинга, сохранение пингов при обновлении подписки и резервном копировании.
- Переключение сервера при работающем VPN требует подтверждения. Автовыбор повторно проверяет настройку перед сменой сервера.
- Выбор файлов выполняется диалогом окна NetPulse; контроллер остаётся доступен для отключения и выхода. Исправлены запоздалые команды, отмена диагностик и обработка остановки службы.
- «Служба TUN» и «Ядра» перенесены в «Настройки». Добавлено предупреждение об удалении файлов антивирусом. Клиент и служба проверяют совпадение комплекта ядер.
- Встроены оригинальные стабильные sing-box 1.14.4 и Xray 26.10.31. Удалены устаревшие описания отдельной сборки sing-box. Из установочного каталога исключена папка docs; лицензии сохранены.
- Очистка удаляет только известные служебные файлы. Сохранены личные данные, посторонние файлы и проверенный комплект для отката.

Подробные проверки и ограничения: [VERIFICATION.md](https://github.com/HACKYASHER/NetPulse/blob/v1.0.7/VERIFICATION.md). Официальные ядра сохранены без изменений; результаты сканирования их зависимостей перечислены в отчёте.
