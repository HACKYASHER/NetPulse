# Установка NetPulse и перенос профиля

[<kbd>English</kbd>](../INSTALLATION.md)

На странице выбора папки установщика можно оставить `C:\Program Files\NetPulse`
или выбрать другую локальную папку, например `D:\NetPulse`. Клиент, ядра, служба и
личные данные хранятся в выбранной папке. Файлы программы и службы принадлежат
администратору. Для работы службы нужен защищённый путь. Установщик проверяет
родительские папки, ссылки и тип диска. При создании родительской папки он
задаёт ей права доступа.

| Путь | Содержимое |
|---|---|
| `NetPulse.exe`, `netpulsed.exe` и библиотеки Qt | Клиент и контроллер |
| `cores` | Официальные Xray 26.10.31 и sing-box 1.14.4 |
| `service` | Защищённые копии службы и ядер |
| `data\<SID Windows>` | Настройки, зашифрованные профили, рабочие ядра, журналы и резервные копии |
| `licenses` | Лицензии и уведомления о распространении |
| `NetPulse-Maintenance.exe`, `Uninstall.exe` | Обновление, восстановление и удаление |

Windows хранит сведения о текущей и прежних папках установки. При переносе
службы установщик проверяет новую копию, переключает путь службы и подтверждает
его в диспетчере служб Windows перед очисткой прежних файлов.

При первом запуске из новой папки NetPulse блокирует исходный профиль на время
копирования и сверяет базу и хеши файлов. Защищённые DPAPI данные остаются
доступны под той же учётной записью Windows. Удаляются известные исходные файлы,
которые совпали с проверенной копией. Изменённые, заблокированные и посторонние
файлы сохраняются. Каждый пользователь Windows переносит свой профиль при
своём первом запуске.

Обновление, восстановление и удаление сохраняют личные данные. После удаления
Windows сохраняет защищённую запись о расположении профиля, чтобы повторная
установка могла использовать эти данные. Открыть папку приложения или профиля
можно из «Настроек».

В комплекте уже есть ядра для первого запуска. Прежние встроенные ядра
обновляются при первом запуске, если их файлы совпадают с оригиналами. Выбранные
вручную ядра сохраняются. Клиент проверяет архивы ядер по SHA-256 и версии,
сохраняет предыдущий комплект для отката и показывает стабильные версии первыми.
Запрос списка версий ограничен 12 секундами. Успешный результат кешируется на
пять минут. Профили Hysteria2 продолжают работать через sing-box при обновлении
Xray.

Переносная версия хранит данные рядом с приложением. Для TUN ей тоже нужна
зарегистрированная защищённая служба Windows. Журналы хранятся пять дней.
Фильтр уровня в «Активности» меняет отображение записей без перезапуска VPN.
