# Архитектура NetPulse

[<kbd>English</kbd>](../../ARCHITECTURE.md)

`NetPulse.exe` работает с обычными правами пользователя и запускает
поставляемый `netpulsed.exe` по абсолютному пути. Контроллер получает
типизированные команды JSON через унаследованные stdin и stdout. Запросы
сопоставляются с ответами по идентификаторам. Размер кадра ограничен 12 МиБ,
одновременно выполняются до восьми запросов. [Список команд](../../backend/commands.json)

Интерфейс получает краткие сведения о профилях. Полная конфигурация запрашивается
при открытии редактора JSON. Учётные данные хранятся в SQLite с защитой DPAPI.
При явном восстановлении резервной копии 3.0.4 используется та же учётная запись
Windows.

Контроллер управляет sing-box и Xray, включая аутентифицированные локальные
мосты между ядрами. Для привилегированных операций TUN он связывается с
`NetPulseService.exe` через именованный канал. Служба проверяет SID, PID,
права доступа и хеши ядер.

| Компонент | Расположение или имя |
|---|---|
| Служба | `NetPulseCoreQt` |
| Канал | `NetPulse.CoreQt.<SID>` |
| Файлы службы | `<папка установки>/service` |
| Профиль | `<папка установки>/data/<SID Windows>` |
| Ядра комплекта | `<папка установки>/cores` |

QLockFile защищает профиль от одновременного открытия двумя клиентами. При
выходе контроллер останавливает управляемые ядра, отменяет диагностику и
восстанавливает собственные изменения System Proxy. Для восстановления
прокси используется отдельный процесс с зашифрованным журналом. Процессы ядер
входят в Windows Job.

Маршрутизация приложений использует имена EXE. Пути, обнаруженные при
сканировании, отдельно используются для значков. `routing-apps.json` хранит
переносную копию правил, а основной профиль хранится в базе.

Обновление клиента проверяет маркер канала Qt и официальный SHA-256 установщика
на GitHub. Временные архивы и старые установщики очищаются. Предыдущий комплект
ядер сохраняется для отката.

Сравнение MTU работает на адаптере текущей сессии TUN. Оно измеряет задержку и
потери, повторяет проверку кандидата и восстанавливает исходный MTU. Рекомендация
применяется вручную. [Установка и перенос профиля](INSTALLATION.md)
