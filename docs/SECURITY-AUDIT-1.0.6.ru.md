# Проверка NetPulse 1.0.6

Проверены исходники и поведение клиента Qt, контроллера Rust, сетевых ядер,
службы TUN, установщика, обновления, хранения данных, импорта и диагностики.
Это проверка конкретного выпуска, а не гарантия отсутствия любых ошибок.
Итоговые результаты прогонов приведены в [VERIFICATION.md](../VERIFICATION.md).

## Найдено и исправлено

| Область | Проблема и результат |
|---|---|
| Установка Xray | Наличие Hysteria2 ошибочно мешало обновить Xray. Проверяются только совместимые комбинации профиля и ядра. |
| Загрузка ядер | Сетевые операции удерживали блокировку контроллера. Загрузка выполняется отдельно; снимки состояния продолжают отвечать. Добавлены тайм-аут и кэш списка выпусков. |
| Параллельные действия | Обновление могло пересекаться со сбросом данных, диагностикой и автоматическим выбором сервера. Операции согласованы общим состоянием; фоновые задачи учитывают его. |
| Обновление клиента | Обычный запуск установщика требовал повышения прав, а между проверкой и запуском оставался изменяемый пользовательский файл. Защищённый помощник принимает только версию, заново получает официальный установщик, проверяет его и запускает из защищённой папки. |
| Канал обновления | Стабильный клиент мог выбрать предварительный выпуск. Стабильный канал теперь исключает prerelease и предварительные теги; помощник также запрещает откат под видом обновления. |
| Папка установки | Одного файла-маркера было недостаточно для доверия существующей папке. До записи проверяются регистрация, владельцы, права и отсутствие ссылок во всём программном дереве. Незавершённая установка может продолжить только защищённую папку, записанную машиной. |
| Создание папок | Защищённые папки теперь создаются сразу с окончательным владельцем и правами. Пустая ранее существовавшая папка пересоздаётся; посторонние файлы не удаляются. |
| Личные данные | Проверяются владелец и тип папки профиля. Права применяются через тот же открытый дескриптор без разрешения замены папки. Чужая папка отклоняется. |
| Обслуживание | Копия установщика создаётся с правами защищённой папки. Источники файлов службы не могут быть сетевыми путями или ссылками. Отметка установленной версии записывается после защиты файлов. |
| Очистка | Обработчики ZIP, временных комплектов и обновлений не переходят по ссылкам за пределы своих папок. Незнакомые файлы сохраняются. |
| Значки приложений | Автоматическое чтение значков не обращается к UNC/SMB и не проходит через точки перенаправления. |
| YAML и QR | Заменён неподдерживаемый YAML-парсер, ограничены глубина, объём, документы и раскрытие ссылок. QR-библиотека обновлена; изображения уменьшаются перед тяжёлой обработкой. Проверены обычный и инвертированный QR. |
| sing-box | Подготовлена явно обозначенная 1.14.4-netpulse.1 с обновлёнными зависимостями и проверенной воспроизводимостью. [Состав сборки](SING-BOX-NETPULSE-BUILD.md). |

## Проверки зависимостей и границы результата

RustSec проверил Cargo.lock по базе RustSec от 28 октября 2026 года
(commit `40f5be6fb12ed93fc591bf4ab23b7d793b3f2239`). После замены YAML и
обновления QR: **0 известных уязвимостей, 0 предупреждений**. Проверка
отозванных публикаций crates.io не входит в этот итоговый прогон.

Для Go выполнены проверка версий модулей OSV и анализ бинарных файлов
govulncheck 1.9.0, база от 27 октября 2026 года. Исправлены найденные
[проблемы HTTP/2](https://pkg.go.dev/vuln/GO-2026-6611) и gRPC и другие
зависимости sing-box. Общее предупреждение OpenPGP остаётся в исходном отчёте,
но соответствующие пакеты отсутствуют в списке реально собранных пакетов.

Официальный Xray 26.10.21 сохранён по запросу пользователя. Сканер отмечает
OpenPGP и HTML в его зависимостях. NetPulse запускает только режим сетевой
конфигурации со строгим списком полей и не передаёт ему HTML/PGP-документы.
Это оценка доступности путей в NetPulse, а не исправление самого upstream Xray.

Qt остаётся версии 6.8.3. В этой версии есть
[известные исправленные позднее проблемы](https://wiki.qt.io/List_of_known_vulnerabilities_in_Qt_products).
Проверенные потоки NetPulse используют обычный текст для данных серверов,
ошибок и журнала, встроенные доверенные SVG и локальные значки EXE. Клиент
не загружает предоставленные подпиской SVG, XML или HTML в Qt. Библиотека
не объявляется свободной от уязвимостей; новые способы обработки таких данных
потребуют повторной проверки и обновления SDK.

Полная установка/перенос службы с реальным TUN и подтверждением UAC,
поведение Касперского и несколько реальных учётных записей Windows в этом
окружении не проверены. Для установщика использован отдельный тестовый
контур с отключёнными действиями над рабочей службой. Два сетевых IPv6-теста
ограничены средой: даже независимые TCP к ::1 и ping -6 не работают.
Системный прокси, маршруты, доверенные сертификаты, антивирус и карантин
не изменялись при этих проверках.
