# NetPulse 1.0.4

Обычный релиз GitHub с исправлениями службы TUN, установщика и журнала.
На предоставленном пользователем снимке контекстная проверка Kaspersky Premium
проверила 3 381 объект за 7 секунд и не обнаружила угроз. Состав проверенного
комплекта и его хеши на снимке не указаны. Обновление службы под защитой
Касперского после этих изменений отдельно не проверялось. Служба не подписана.

## Диагностика службы и прокси

Если Windows продолжает видеть службу после удаления её регистрации, ошибка
чтения конфигурации показывается отдельно. Установщик прекращает повторные
попытки до устранения этого состояния.

Если системный прокси или локальный порт использует другой клиент, NetPulse
объясняет конфликт и сохраняет его настройки и действующее подключение.

Windows 2 означает, что файл не найден; для конфигурации службы в данном случае
наблюдается отсутствующая запись регистрации:
[Microsoft: коды системных ошибок](https://learn.microsoft.com/en-us/windows/win32/debug/system-error-codes--0-499-).
Удаление службы может ожидать освобождения открытых дескрипторов:
[Microsoft: DeleteService](https://learn.microsoft.com/en-us/windows/win32/api/winsvc/nf-winsvc-deleteservice).
Данные проверки не доказывают, что именно удерживает повреждённую запись SCM.

## Исправления

- Ошибка чтения регистрации больше не выводится как `Some(2)` или просьба
  подтвердить UAC. Клиент показывает повреждённое состояние службы отдельно.
- Проверка выполняется до запуска помощника с повышенными правами. Для такого
  состояния повторная установка не запускается.
- Помощник, контроллер и установщик сохраняют разные коды: отсутствующие или
  заблокированные компоненты, неподтверждённая остановка, повреждённая регистрация,
  отменённый UAC и ожидающее завершения удаление.
- Установщик использует русские и английские сообщения. «Повтор» доступен только
  после отмены UAC. В остальных случаях установка приложения завершается с
  указанием, что TUN не готов; автоматическому установщику возвращается код сбоя.
- После удаления регистрации старые папки обновления NetPulse сами по себе не
  блокируют новую установку. Их оригиналы сохраняются для расследования; ссылки,
  посторонние файлы и уже существующие основные компоненты по-прежнему блокируют
  замену. До исчезновения повреждённой регистрации установка не запускается.
- Конфликт системного прокси объясняется на русском, с адресом локального прокси,
  если его можно безопасно показать. Пароли и адрес PAC в журнал не попадают.
- В настройках подключения есть кнопка параметров прокси Windows и пояснение,
  почему смена локального порта сама по себе не решает конфликт System Proxy.

При проверке выявлены ошибки двух локальных тестовых серверов: режим принятого
сокета не задавался явно, а разрешённые повторные HTTP-запросы ошибочно считались
нарушением маршрутизации. В тестах явно задан блокирующий режим и проверяется,
что запрещённый маршрут не достигает локального сервера. Рабочие правила
маршрутизации и DNS этим исправлением не меняются.

После завершения действий антивируса нужно закрыть NetPulse и установщик и
перезапустить Windows, затем заново проверить состояние службы. Перезапуск здесь
рекомендуется для текущего повреждённого состояния; он не заменяет проверку
срабатывания антивируса и не гарантирует, что установка службы будет разрешена.
