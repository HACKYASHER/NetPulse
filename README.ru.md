# NetPulse 1.0.5

Нативная Windows x64 версия NetPulse на C++ / Qt 6.8.3 / QML.
Основа — точные исходники NetPulse 3.0.4 из `ONE/release-v2/NetPulse-Source.zip`.
Сетевой контроллер сохранён на Rust и вынесен в `netpulsed.exe`; служба TUN —
отдельный `NetPulseService.exe`. React, Tauri и WebView2 для запуска не нужны.

## Запуск

Откройте `release/NetPulse/NetPulse.exe` или установите
`release/NetPulse-Setup.exe`. Для переносной версии сохраняйте рядом с EXE
всю папку: библиотеки Qt, `qml`, `cores` и плагины.

1. В разделе «Серверы» добавьте ключ, файл, QR-код или HTTPS-подписку.
2. Выберите сервер. Нажмите кнопку питания в «Обзоре» и выберите TUN, System Proxy или оба режима, затем подтвердите подключение.
3. Для TUN требуется служба: установщик добавляет её с подтверждением UAC.
   Её также можно установить или восстановить во вкладке «Сеть → Служба TUN».
4. При выходе через меню трея клиент отключает соединение и восстанавливает
   собственное изменение системного прокси.

Приложение и служба установлены в `C:\Program Files\NetPulse`, личные данные —
в её подпапке `data\<SID Windows>`. Прежний Qt-профиль из
`%LOCALAPPDATA%\NetPulseQt` переносится при первом запуске с проверкой копии.
Данные исходного NetPulse 3.0.4 не копируются автоматически. Для переноса создайте резервную копию
в 3.0.4 и восстановите её в «Настройки → Восстановить» под той же учётной
записью Windows. Это явная операция: восстановление заменяет данные Qt-клиента.
Одновременно подключать обе версии не следует: они управляют сетью одной ОС.

## Возможности

- Восемь разделов: обзор, серверы с подписками, маршрутизация, сеть,
  диагностика, Playground, активность и настройки.
- Закрепление серверов, действия через ПКМ, автообновление подписок при
  запуске и по интервалу, импорт ключей, файлов и QR.
- sing-box 1.14.3 и Xray 26.10.17 с проверкой SHA-256, обновлением и откатом.
- Маршрутизация по имени EXE, значки приложений, импорт/экспорт правил,
  отдельный routing-apps.json и исключения доменов.
- Вкладки сети с DNS, MTU, SNI/TLS, фрагментацией, multiplex и службой TUN.
- Ручные проверки пинга с сохранением результатов, Speed Test и сравнение MTU.
- Playground с группами процессов, сетевыми счётчиками, маршрутами и
  событиями соединений; цветная консоль журналов с копированием.
- Проверка обновлений клиента при запуске и каждые шесть часов. Старый
  канал 3.0.4 исключён из обновлений новой архитектуры.
- SQLite/DPAPI, резервные копии, расширенный трей, автозапуск и темы RU/EN.


## Сборка из исходников

Нужны Qt 6.8.3 MSVC x64, MSVC 2022 и Windows SDK, Rust 1.88 или новее,
Python, CMake и Ninja. Для скрипта загрузки Qt дополнительно нужен `py7zr`.

```powershell
python -m pip install cmake ninja py7zr
python scripts/fetch-qt.py
# В Developer PowerShell для Visual Studio:
python scripts/build.py --qt .tools/Qt
python scripts/package.py
```

`QTDIR` задаёт иной SDK Qt. `NETPULSE_TOOLCHAIN` позволяет использовать переносной
Rust/MSVC SDK из `.local/toolchain`. В данной рабочей среде скрипт также находит
уже подготовленный SDK соседнего проекта `ONE`; исходники приложения от него
не зависят. Параметр `--cargo-target` позволяет повторно использовать кеш сборки.
Установщик собирается NSIS 3 (`NSIS_EXE` либо `makensis` в PATH).

```powershell
python scripts/test-ipc.py
release/NetPulse/NetPulse.exe --smoke-test C:/Temp/NetPulseQt-smoke
cd backend
cargo test -p netpulse-core --lib
```

Результаты выполненных проверок находятся в `VERIFICATION.md` и
`release/VERIFICATION.json`. Полноценная проверка TUN с реальным сервером,
повышением прав и физическим сетевым адаптером отдельно не выполнена.
Приложение и установщик не подписаны сертификатом издателя.

## Лицензия

Код NetPulse — GPL-3.0-or-later, как в исходном релизе. Qt подключается динамически;
его DLL можно заменить совместимой сборкой. Исходники клиента и изменения
контроллера поставляются отдельно. Лицензии, исходные проекты и версии —
в `THIRD-PARTY.md`, `licenses/` и `cores/source-manifest.json`.


## Обновлённый интерфейс 1.0.3 beta

Серверы и подписки объединены. Действия с сервером открываются правой кнопкой
мыши; закреплённые серверы находятся сверху. Подписки обновляются при запуске
и через заданный интервал. Список приложений и доменных исключений изначально
пуст: примеры в полях служат только подсказкой.

В «Сеть» настройки распределены по вкладкам: подключение, DNS, MTU, SNI/TLS,
транспорт, служба TUN, ядра и Sniffing. Рядом с параметрами приведены пояснения.
Playground показывает сетевые данные процессов, журнал наблюдаемых соединений
и позволяет задать маршрут для EXE. Счётчики трафика доступны только для
соединений, видимых ядру NetPulse.

Для MTU доступно последовательное сравнение каждого значения диапазона
(по умолчанию 1440–1472) на текущем TUN-соединении, до пяти проверок на значение.
Тест запускается вручную и может прерывать соединения приложений. Он сравнивает
потери, медиану задержки и джиттер, повторяет лучшего кандидата и проверяет
исходный MTU в начале и конце. Исходный MTU восстанавливается; рекомендация
применяется отдельной кнопкой. Скорость скачивания этим тестом не измеряется:
для неё сравните результаты Speed Test после применения MTU.

Выбор ядра сохраняется и применяется с проверкой совместимости. При ошибке
смены клиент сохраняет или восстанавливает предыдущее рабочее подключение.
Sniffing читает метаданные TUN без расшифровки TLS. System Proxy использует
адрес из запроса приложения без ожидания первых данных.

Установщик предлагает обновление, восстановление и удаление с сохранением
настроек. Служба TUN устанавливается через стандартное окно UAC. Временные
архивы ядер и незавершённые загрузки очищаются автоматически; предыдущий
комплект ядер сохраняется для отката.

## Исправления 1.0.3 beta

Выделение журнала прокручивается за курсором, а копирование выдаёт обычный текст. В Обзоре появился быстрый выбор сервера с поиском. Ускорена смена серверов и ядер с сохранением проверок и отката. Исправлены исключения Sniffing, счётчик подписки и полоса трафика со сроком действия ключа. Подробности: [проверка исправлений](docs/FIXES-1.0.2.md).

## Журнал и IPv6 — 1.0.3 beta

Исправлена передача уровня журналирования обоим ядрам, добавлены INFO-соединения и выбор уровня в Активности. Категории учитывают прокрутку и ротацию файлов. В Сети появился выбор IPv6 в TUN с автоматическим учётом физического маршрута для выборочного VPN. Подробности: [проверка журналов](docs/FIXES-1.0.3.md).
