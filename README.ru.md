# NetPulse 1.0.0 beta — Qt Desktop

Нативная Windows x64 версия NetPulse на C++ / Qt 6.8.3 / QML.
Основа — точные исходники NetPulse 3.0.4 из `ONE/release-v2/NetPulse-Source.zip`.
Сетевой контроллер сохранён на Rust и вынесен в `netpulsed.exe`; служба TUN —
отдельный `NetPulseService.exe`. React, Tauri и WebView2 для запуска не нужны.

## Запуск

Откройте `release/NetPulse/NetPulse.exe` или установите
`release/NetPulse-Setup.exe`. Для переносной версии сохраняйте рядом с EXE
всю папку: библиотеки Qt, `qml`, `cores` и плагины.

1. В разделе «Серверы» добавьте ключ, файл, QR-код или HTTPS-подписку.
2. Выберите сервер. В «Обзоре» включите System Proxy и/или TUN.
3. Для TUN установите отдельную службу в разделе «Сеть». Windows покажет UAC.
4. Нажмите кнопку питания. При выходе через меню трея клиент отключает соединение
   и восстанавливает собственное изменение прокси.

Новая версия хранит данные в `%LOCALAPPDATA%\NetPulseQt`. Данные исходного
NetPulse не копируются автоматически. Для переноса создайте резервную копию
в 3.0.4 и восстановите её в «Настройки → Восстановить» под той же учётной
записью Windows. Это явная операция: восстановление заменяет данные Qt-клиента.
Одновременно подключать обе версии не следует: они управляют сетью одной ОС.

## Возможности

- Отдельное окно на Qt Quick: обзор, серверы, подписки, маршрутизация, сеть,
  диагностика, Playground, активность, настройки и ядра.
- Импорт и редактирование профилей; защищённые подписки, ручное и периодическое
  обновление; выбор сервера и проверка задержки.
- sing-box 1.14.3 и Xray 26.10.17 из исходной поставки с проверкой SHA-256.
  System Proxy, TUN, общая маршрутизация и списки приложений.
- DNS, MTU, переключение транспортного ядра; остальные параметры сохранённого
  контроллера доступны через «Расширенные параметры» в редакторе JSON.
  Там же доступны TLS, фрагментация, multiplex и расширенные правила.
- Отменяемые проверки задержки, выбор лучшего сервера, HTTPS Speed Test с
  ограничением трафика, анализ MTU, наблюдение за соединениями процессов.
- SQLite и Windows DPAPI, резервные копии, ограниченные журналы, трей,
  автозапуск, светлая/тёмная/системная тема, RU/EN.

Это новая реализация интерфейса, а не побайтовая копия прежних экранов. В этой
версии нет автоматического обновления самого клиента из канала 3.x: такой
установщик заменил бы Qt-приложение на старую архитектуру. Обновления сетевых
ядер остаются доступны. Каталог приложений ограничивает показ первыми 150
совпадениями; поиск позволяет сузить список.

## Структура

```text
src/                         C++ окно, трей и частный транспорт к контроллеру
qml/                         QML экраны и общие компоненты
backend/crates/netpulse-core  Сохранённое сетевое ядро Rust
backend/crates/netpulse-host  Отдельный контроллер, 64 типизированные команды
backend/crates/netpulse-service  Windows-служба TUN
resources/cores/              Проверенные sing-box, Xray, libcronet
scripts/                     Сборка, упаковка и проверки
licenses/                    Лицензии и сведения о происхождении
release/NetPulse/             Готовая переносная версия
release/NetPulse-Setup.exe Установщик
```

## Сборка из исходников

Нужны Qt 6.8.3 MSVC x64, MSVC 2022 и Windows SDK, Rust 1.88 или новее,
Python, CMake и Ninja. Для скрипта загрузки Qt дополнительно нужен `py7zr`.

```powershell
python -m pip install cmake ninja py7zr
python scripts/fetch-qt.py
# В Developer PowerShell для Visual Studio:
python scripts/build.py --qt .tools/Qt
python scripts/package.py
```

`QTDIR` задаёт иной SDK Qt. `NETPULSE_TOOLCHAIN` позволяет использовать переносной
Rust/MSVC SDK из `.local/toolchain`. В данной рабочей среде скрипт также находит
уже подготовленный SDK соседнего проекта `ONE`; исходники приложения от него
не зависят. Параметр `--cargo-target` позволяет повторно использовать кеш сборки.
Установщик собирается NSIS 3 (`NSIS_EXE` либо `makensis` в PATH).

```powershell
python scripts/test-ipc.py
release/NetPulse/NetPulse.exe --smoke-test C:/Temp/NetPulseQt-smoke
cd backend
cargo test -p netpulse-core --lib
```

Результаты выполненных проверок находятся в `VERIFICATION.md` и
`release/VERIFICATION.json`. Полноценная проверка TUN с реальным сервером,
повышением прав и физическим сетевым адаптером отдельно не выполнена.
Приложение и установщик не подписаны сертификатом издателя.

## Лицензия

Код NetPulse — GPL-3.0-or-later, как в исходном релизе. Qt подключается динамически;
его DLL можно заменить совместимой сборкой. Исходники клиента и изменения
контроллера поставляются отдельно. Лицензии, исходные проекты и версии —
