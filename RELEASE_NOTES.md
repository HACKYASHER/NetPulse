# NetPulse 1.0.5

Исправлено восстановление службы TUN при ошибке Windows 3: регистрация службы
сохранялась, а папка с её файлами отсутствовала.

- «Восстановить службу» теперь выполняет отдельное восстановление проверенного комплекта с подтверждением Windows.
- Повторная установка корректно обрабатывает оставшуюся регистрацию без файлов службы.
- Ошибка показывает полный отсутствующий путь; удаление службы работает и при отсутствии её папки.
- Автоматическое подключение не восстанавливает файлы. Исчезновение компонента во время операции останавливает восстановление.

Установите поверх текущей версии, сохранив настройки и подписки. Затем при необходимости откройте «Сеть → Служба TUN → Восстановить службу».
